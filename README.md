# Student Management System

A console-based Java application for managing student records, marks, and results.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Add Student Marks
- Calculate Total and Percentage
- Generate Grade
- Check Pass/Fail Result
- File Handling for saving and loading student data
- Exception Handling for invalid input

## Technologies Used

- Java
- OOP
- Collections
- File Handling
- Exception Handling

## Project Structure

- `Main.java` - Main menu and user interaction
- `Student.java` - Student data and result calculation
- `StudentManager.java` - Student management operations
- `FileHandler.java` - Saving and loading student data

## How It Works

The application provides a menu-driven interface where users can add, search, update, and delete student records.

Student marks can also be added to calculate:

- Total Marks
- Percentage
- Grade
- Pass/Fail Result

Student data is saved in a text file so that records can be loaded when the application starts again.
